### 1. DON’T (2026.02 ~ 2026.03)
**‘삼성 청년 SW AI 아카데미’ 교육생 대상 맞춤형 지출 관리 및 저축 플랫폼**
- **구성 및 역할:** 6인 팀 프로젝트 / 금융 및 랭킹 도메인 백엔드 개발
- **사용 기술:** Java, Spring Boot, PostgreSQL, Redis, React, Nginx, Jenkins, Docker, FastAPI, CatBoost, SHAP, DiCE

**💡 주요 성과 및 트러블슈팅**
* **Event-Driven 아키텍처를 통한 서비스 격리:** 저축 트랜잭션과 랭킹 갱신 로직이 강결합될 경우, 랭킹 서버 장애가 핵심 금융 로직에 전파될 위험을 발견했습니다. 이를 해결하기 위해 Spring Event를 활용한 비동기 이벤트 기반 아키텍처를 도입하여 금융 서비스와 랭킹 서비스를 완전히 분리했습니다.
* **비동기 스레드 풀 및 Redis ZSET 최적화:** 동시 접속자 1만 명 이상의 대규모 이벤트 발생 시 데이터베이스 병목을 방지하고자, 별도의 비동기 스레드 풀에서 이벤트를 구독하도록 설계했습니다. 또한, 랭킹 산출에 최적화된 Redis의 Sorted Set 자료구조를 활용하여 복잡한 쿼리 없이 O(log(N))의 속도로 실시간 랭킹을 갱신. 동시 접속 환경에서도 지연 없는 랭킹 시스템을 제공하며 코어 금융 로직의 안정성을 확보하였습니다.
* **SSE CPU 과부화 해결:** 랭킹 변동 알림을 위해 도입한 SSE 통신 과정에서, 다수의 클라이언트에게 알림을 전송할 때 발생하는 반복적인 JSON 직렬화 연산이 CPU 부하를 유발하는 것을 파악. 직렬화 로직을 루프 외부로 분리하여 O(N)에서 O(1)로 연산 복잡도를 최적화 했습니다.
